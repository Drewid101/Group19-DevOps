**USE CASE 5: VIEW CAPITAL CITY POPULATION**

Goal in Context: To allow users to retrieve a system generated report of all the capital cities in the world, continent or region organized by largest to smallest population.

Primary Actor: Data Analyst or any authorized user who needs population data.

Scope: Population Information System

Level: Primary Task

Preconditions:

- The system is properly connected to the database.
- The SQL database contains verified and up-to-date information on cities, countries, their population, and an indication of which are capital cities.
- The required reporting or analysis tools must be available in the system.
- User has the necessary permissions to access the population records or reports.
- The relationships between continents, regions, cities, and countries are correctly defined and maintained in the database.

Success End Condition: The user successfully views and/or exports a report of all the capital cities in the world, ordered in descending order by population.

Failed End Condition: The report cannot be generated due to missing data, failed database connection, system error, or insufficient access permissions. System displays an appropriate error message

Trigger: The user selects to run the "Capital City Population Report" option in the Population Information System.

Main Success Scenario:

1. The user logs into the Population Information System.
2. The system verifies the user's login credentials.
3. The user navigates to the Reports section.
4. From the available reports the user selects "Capital City Population Report"
5. The system prompts the user to select a report filter: world, continent, or region.
6. The user selects a filter.
7. The system constructs the appropriate SQL query based on the user's input.
8. The system executes the query to retrieve all the capital cities that matches the filter, and their populations.
9. The system sorts the results from largest to smallest in order in population size.
10. The system generates and displays the report.
11. The user views the report and may export it to CSV, Excel or PDF.
12. The system logs that the report has been successfully generated (user, timestamp, parameters).
