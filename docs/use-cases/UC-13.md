**USE CASE 13: POPULATION REPORT GENERATION**

Goal in Context: To allow users to retrieve a system generated population report depicting the name and the total population of the continent/region/country, along with the total population living in and out of cities, of the continent/region/country also given as percentage.

Primary Actor: Data Analyst or any authorized user who needs population data.

Scope: Population Information System

Level: Primary Task

Preconditions:

- SQL Database available with accurate, verified, up to date data for cities, countries, continents, regions, and populations.
- Total population living in cities and outside of cites exists in the database or can be calculated (population living outside is the difference between total population and population living inside)
- The system is properly connected to the database.
- The required reporting or analysis tools are available in the system.
- User has the necessary permissions to access the population records or reports.
- Relationships between cities, countries, regions, and continents are properly defined.

Success End Condition: The user successfully views the system generated population Report with the columns including the name of the country, continent, or region, along with their total population, the population in cities (also as a percentage) and population outside of cites (also as a percentage).

Failed End Condition: The report cannot be generated due to missing data, failed database connection or system error, or insufficient access permissions. System displays an appropriate error message.

Trigger: The user selects to run the "Population Report" option in the Population Information System.

Main Success Scenarios:

1. The user logs into the Population Information System.
2. The system verifies the user's login credentials.
3. The user navigates to the Reports section.
4. From the available reports the user selects "Population Report."
5. The system prompts the user to select a report filter: continent, region, or country.
6. The user selects a filter.
7. The system constructs the appropriate SQL query to retrieve total population data for the selected criteria, Population living in cities and the percentage of total, and Population not living in cities and the percentage of total.
8. The system executes the query.
9. The system generates and displays the report with the retrieved columns in a table format.
10. The user views the reports and may export it to CSV, Excel or PDF.
11. The system logs that the report has been successfully generated (user, timestamp, parameters).
