**USE CASE 8: GEOGRAPHIC POPULATION**

Goal in Context: To allow users to retrieve a system generated report with the population of the world, continent, region, country, district, or city.

Primary Actor: Data Analyst or any authorized user who needs population data.

Scope: Population Information System

Level: Primary Task

Preconditions:

- SQL Database available with accurate, verified, up to date population data on cities, countries, world, continents, districts, regions.
- The system is properly connected to the database.
- The required reporting or analysis tools are available in the system.
- User has the necessary permissions to access the population records or reports.
- Relationships between cities, countries, regions, districts and continents are properly defined.

Success End Condition: The user successfully views the system generated report with the population of the world, continent, region, country, district, or city.

Failed End Condition: The report cannot be generated due to missing data, failed database connection or system error, or insufficient access permissions. System displays an appropriate error message.

Trigger: The user selects to run the "Population by Geographic Level Report" option in the Population Information System.

Main Success Scenarios:

1. The user logs into the Population Information System.
2. The system verifies the user's login credentials.
3. The user navigates to the Reports section.
4. From the available reports the user selects "Population by Geographic Level Report."
5. The system prompts the user to select a report filter criteria: world, continent, region, country, district, or city.
6. The user selects a filter.
7. The system constructs the appropriate SQL query to retrieve population data for the selected criteria.
8. The system executes the query.
9. The system generates and displays the report.
10. The user views the reports and may export it to CSV, Excel or PDF.
11. The system logs that the report has been successfully generated (user, timestamp, parameters).
