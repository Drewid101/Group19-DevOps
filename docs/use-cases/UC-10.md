**USE CASE 10: COUNTRY REPORT GENERATION**

Goal in Context: To allow users to retrieve a system generated country report listing the code, name, continent, region, population and capital of a country.

Primary Actor: Data Analyst or any authorized user who needs population data.

Scope: Population Information System

Level: Primary Task

Preconditions:

- SQL Database available with accurate, verified, up to date data for countries, continents, regions, with their populations and capitals.
- The system is properly connected to the database.
- The required reporting or analysis tools are available in the system.
- User has the necessary permissions to access the population records or reports.
- Relationships between cities, countries, regions, and continents are properly defined.

Success End Condition: The user successfully views the system generated report of a country with the code, name, continent, region, population and capital listed.

Failed End Condition: The report cannot be generated due to missing data, failed database connection or system error, or insufficient access permissions. System displays an appropriate error message.

Trigger: The user selects to run the "Country Report" option in the Population Information System.

Main Success Scenarios:

1. The user logs into the Population Information System.
2. The system verifies the user's login credentials.
3. The user navigates to the Reports section.
4. From the available reports the user selects "Country Report."
5. The system constructs an SQL query to retrieve the code, name, continent, region, population and capital of each country.
6. The system executes the query.
7. The system generates and displays the report with the retrieved columns in a table format.
8. The user views the reports and may export it to CSV, Excel or PDF.
9. The system logs that the report has been successfully generated (user, timestamp, parameters).
