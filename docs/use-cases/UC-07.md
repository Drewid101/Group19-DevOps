**USE CASE 7: THE POPULATION DISTRIBUTION OF PEOPLE LIVING IN AND OUTSIDE OF THE CITY.**

Goal in Context: To allow users to retrieve a system generated report of the total population, the population living in cities, and the population living outside of the cities, of a given continent, region or country. User ability to analyse people living in cities vs people living outside of cities.

Primary Actor: Data Analyst or any authorized user who needs population data.

Scope: Population Information System

Level: Primary Task

Preconditions:

- SQL Database available with accurate, verified, up to date population data on cities, countries, continents, regions.
- Population living inside cities is identifiable as the sum of populations in cities; Population living outside of cities is the difference between total population and Population living inside cities
- The system is properly connected to the database.
- The required reporting or analysis tools are available in the system.
- User has the necessary permissions to access the population records or reports.
- Relationships between cities, countries, regions, and continents are properly defined.

Success End Condition: The user successfully views the system generated report with the total population, people living in the city, people living outside of the city, of a given continent, region, or country.

Failed End Condition: The report cannot be generated due to missing data, failed database connection or system error, or insufficient access permissions. System displays an appropriate error message.

Trigger: The user selects to run the "Population Distribution Report" option in the Population Information System.

Main Success Scenarios:

1. The user logs into the Population Information System.
2. The system verifies the user's login credentials.
3. The user navigates to the Reports section.
4. From the available reports the user selects "Population Distribution Report"
5. The system prompts the user to select a report filter: by country, continent, or region.
6. The user selects a filter.
7. The system constructs a SQL query to retrieve: Total population per selection, sum of all the people living in cities in selection, and the Total population per selection - sum of all the people living in cities in that unit to give the people living outside of the city.
8. The system executes the query and organizes results by continent, region, or country.
9. The system generates and displays the report.
10. The user views the reports and may export it to CSV, Excel or PDF.
11. The system logs that the report has been successfully generated (user, timestamp, parameters).
