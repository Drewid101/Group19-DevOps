**USE CASE 4: TOP N POPULATED CITIES**

Goal in Context: To allow users to retrieve a system generated report of the top N populated cities in the world, continent, region, country, or district, where N is a value provided by the user.

Primary Actor: Data Analyst or any authorized user who needs population data.

Scope: Population Information System

Level: Primary Task

Preconditions:

- SQL Database with verified up to date population data on countries, continents, regions and districts is available.
- The system is properly connected to the database.
- The required reporting or analysis tools are available in the system.
- User has the necessary permissions to access the population records or reports.
- The relationships between continents, regions, districts, and countries are correctly defined and maintained in the database.

Success End Condition: The user successfully views the ranked list of the top _N_ populated cities in the world, continent, or region, country, or district

Failed End Condition: The report cannot be generated due to unrecognized _N_ value, missing data, failed database connection, system error, or insufficient access permissions. System displays an appropriate error message.

Trigger: The user selects to run the "Top _N_ Populated Cities" option in the Population Information System.

Main Success Scenarios:

1. The user logs into the Population Information System.
2. The system verifies the user's login credentials.
3. The user navigates to the Reports section.
4. From the available reports the user selects "Top _N_ Populated Cities"
5. The system prompts the user to select a report filter: by world, continent, or region, country, or district.
6. The user selects a filter.
7. The system then prompts the user to enter a value for _N._
8. The user enters the desired number _N._
9. The system validates the input and constructs a query to retrieve the top N cities by population, in the world, continent, or region, country, or district.
10. The system executes the SQL query.
11. The system generates and displays the report.
12. The user views the reports and export it to CSV, Excel or PDF.
13. The system logs that the report has been successfully generated.
