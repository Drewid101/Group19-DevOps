**USE CASE 3: VIEW CITY POPULATION**

Goal in Context: To allow users to retrieve a system generated report of the cities in the world, continent, region, country, or district, sorted by largest to smallest population.

Primary Actor: Data Analyst or any authorized user who needs population data.

Scope: Population Information System

Level: Primary Task

Preconditions:

- The system is properly connected to the database.
- SQL Database with verified up to date population data on countries, continents, regions available.
- The required reporting or analysis tools must be available in the system.
- User has the necessary permissions to access the population records or reports.
- The relationships between continents, regions, and countries are correctly defined and maintained in the database.

Success End Condition: The user successfully views and/or exports a report of all the cities, filtered by the world, continent, region, country, or district, and sorted by largest to smallest population.

Failed End Condition: The report cannot be generated due to missing data, failed database connection, system error, or insufficient access permissions. System displays an appropriate error message

Trigger: The user selects to run the "City Population Report" option in the Population Information System.

Main Success Scenarios:

1. The user logs into the Population Information System.
2. The system verifies the user's login credentials.
3. The user navigates to the Reports section.
4. From the available reports the user selects "City Population Report"
5. The system prompts the user to select a report filter: by world, continent, region country, or district.
6. The user selects the desired filter.
7. The system constructs the appropriate SQL query based on the user's selected filter.
8. The system executes the query to retrieve the cities and their populations in the selected scope.
9. The system sorts the results from largest to smallest in order of population.
10. The system generates and displays the report.
11. The user views the reports and may export it to CSV, Excel or PDF.
12. The system logs that the report has been successfully generated.
