**USE CASE 12: CAPITAL CITY REPORT GENERATION**

Goal in Context: To allow users to retrieve a system generated report of capital cities listing their name, country, and population.

Primary Actor: Data Analyst or any authorized user who needs population data.

Scope: Population Information System

Level: Primary Task

Preconditions:

- SQL Database available with accurate, verified, up to date data for cities, countries, populations, and an indication of which are capital cities.
- The system is properly connected to the database.
- The required reporting or analysis tools are available in the system.
- User has the necessary permissions to access the population records or reports.
- Relationships between cities, countries, districts and population are properly defined.

Success End Condition: The user successfully views the system generated report of a Capital city with their name, country, and population listed.

Failed End Condition: The report cannot be generated due to missing data, failed database connection or system error, or insufficient access permissions. System displays an appropriate error message.

Trigger: The user selects to run the "Capital City Report" option in the Population Information System.

Main Success Scenarios:

1. The user logs into the Population Information System.
2. The system verifies the user's login credentials.
3. The user navigates to the Reports section.
4. From the available reports the user selects "Capital City Report."
5. The system constructs an SQL query to retrieve the name, country, and population of each capital city.
6. The system executes the query.
7. The system generates and displays the report with the retrieved columns in a table format.
8. The user views the report and may export it to CSV, Excel or PDF.
9. The system logs that the report has been successfully generated (user, timestamp, parameters).
