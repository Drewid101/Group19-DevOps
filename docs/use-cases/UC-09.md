**USE CASE 9: THE POPULATION BY LANGUAGE**

Goal in Context: To allow users to retrieve a system generated report of the population of people who speak selected languages (Chinese, English, Hindi, Spanish, and Arabic) ranked by largest to smallest, including the percentage of the world population for each language.

Primary Actor: Data Analyst or any authorized user who needs population data.

Scope: Population Information System

Level: Primary Task

Preconditions:

- SQL Database available with accurate, verified, up to date population data by country, along with the primary languages spoken.
- Total world population is available or can be calculated from the database.
- The system is properly connected to the database.
- The required reporting or analysis tools are available in the system.
- User has the necessary permissions to access the population records or reports.
- Relationships between countries, languages, continents are properly defined.

Success End Condition: The user successfully views the system generated report with the number of persons who speak a selected language, in descending order, including the percentage of the world population for each language.

Failed End Condition: The report cannot be generated due to missing data (e.g. language), failed database connection or system error, or insufficient access permissions. System displays an appropriate error message.

Trigger: The user selects to run the "Population by Language Report" option in the Population Information System.

Main Success Scenarios:

1. The user logs into the Population Information System.
2. The system verifies the user's login credentials.
3. The user navigates to the Reports section.
4. From the available reports the user selects "Population by Language Report."
5. The system retrieves the total world population from the database.
6. The system constructs the appropriate SQL query to retrieve population data for the world.
7. The system constructs the appropriate SQL query to retrieve population counts of speakers for selected languages: Chinese, English, Hindi, Spanish, and Arabic.
8. The system constructs the appropriate SQL query to calculate the percentage of world population for each language.
9. The system executes the query and sorts the results from largest to smallest number of speakers.
10. The system generates and displays the report in a table.
11. The user views the reports and may export it to CSV, Excel or PDF.
12. The system logs that the report has been successfully generated (user, timestamp, parameters).
