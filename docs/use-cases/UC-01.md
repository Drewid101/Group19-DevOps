**USE CASE 1: GLOBAL POPULATION DATA**

Goal in Context: To allow users to retrieve a system generated report on all the countries in the world, a continent, or a region organized by largest to smallest population.

Primary Actor: Data Analyst or any authorized user who needs population data.

Scope: Population Information System

Level: Primary Task

Preconditions:

- SQL Database available with accurate, verified, up to date population data on countries, continents, regions.
- The required reporting or analysis tools are available in the system.
- The system is properly connected to the database.
- The user has the necessary permissions to access the population records or reports.
- The relationships between continents, regions, and countries are correctly defined and maintained in the database.

Success End Condition: The user successfully views a system generated report listing all the countries in the world, continent, or region, sorted by population in descending order.

Failed End Condition: The report cannot be generated because due to missing data, failed database connection or system error, or insufficient access permissions. System displays an appropriate error message.

Trigger: The user selects to run the "Global Population Report" option in the Population Information System.

Main Success Scenarios:

1. The user logs into the Population Information System.
2. The system verifies the user's login credentials.
3. The user navigates to the Reports section.
4. From the available reports the user selects "Global Population Report"
5. The system prompts the user to select a report filter criteria: by world, continent, or region.
6. The user selects a filter.
7. The system sends an SQL query to retrieve population data for all countries, continents or regions.
8. The system sorts the results by largest to smallest population
9. The system generates and displays the report.
10. The user views the reports and may export it to CSV, Excel or PDF.
11. The system logs that the report has been successfully generated(user,

Time stamp, parameters).
